# TikTok Domain Verification Site

Arquivos mínimos para publicar no GitHub Pages e verificar domínio no TikTok Developer.

## Conteúdo
- `index.html`
- `privacy.html`
- `terms.html`
- `tiktokC9JjTVO1AEq5tMbMMK9ocw4eGDF7oTnZ.txt` (arquivo de verificação)

## Publicação rápida
1. Crie um repositório no GitHub com este conteúdo.
2. Push para branch `main`.
3. Em **Settings → Pages**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
4. Aguarde URL do Pages.
