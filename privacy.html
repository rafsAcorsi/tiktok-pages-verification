Política de Privacidade

Última atualização: 22/10/2026

Esta aplicação é usada para autenticar conta TikTok e permitir envio de vídeos autorizado pelo próprio usuário.

Dados coletados

  • Identificadores básicos da conta TikTok autorizada (quando fornecidos pela API).
  • Tokens de acesso necessários para publicar conteúdo em nome do usuário.
  • Metadados técnicos mínimos para funcionamento e segurança.

Uso dos dados

  • Autenticar a sessão do usuário no TikTok.
  • Publicar vídeos solicitados explicitamente pelo usuário.
  • Registrar estado de processamento e histórico operacional.

Compartilhamento

Não vendemos dados pessoais. Dados só são compartilhados com provedores necessários para executar a funcionalidade (ex.: TikTok API), conforme autorização do usuário.

Retenção

Dados técnicos e tokens ficam armazenados apenas pelo período necessário ao funcionamento da integração, podendo ser removidos pelo operador da aplicação.

Contato

Para dúvidas sobre privacidade, entre em contato pelo e-mail informado no perfil do projeto.
